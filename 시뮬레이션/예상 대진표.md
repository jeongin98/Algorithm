### 문제 분석 요약
- N명의 참가자가 토너먼트로 겨루고, A번 참가자와 B번 참가자가 몇 번째 라운드에서 만나게 되는지 구하는 문제이다.
- 토너먼트에서 번호는 매 라운드마다 (번호 + 1) // 2 방식으로 갱신된다.
    - 즉, 홀수·짝수 상관없이 다음 라운드 번호를 계산할 수 있다.
- A와 B는 서로 만나기 전까지는 모두 이긴다고 가정한다.
- 두 번호가 같아지는 순간이 바로 두 선수가 만나는 라운드이다.

### 알고리즘 설계

#### 필요한 값

- 입력:
    - n: 전체 참가자 수 (2 ≤ n ≤ 2^20)
    - a: 참가자 A의 번호
    - b: 참가자 B의 번호
- 출력: 두 참가자가 처음 만나는 라운드 번호

#### 풀이 순서

1. A와 B가 같지 않는 동안 반복:
2. 한 라운드가 끝날 때마다 번호가 다음과 같이 갱신된다.
    - a = (a + 1) // 2
    - b = (b + 1) // 2
        → 이는 토너먼트에서 번호가 승자 기준으로 재정렬되는 규칙과 동일하다.

3. 라운드 수를 1 증가시킨다.
4. A == B가 되면 반복을 종료한다.
5. 지금까지 증가한 라운드 수를 반환한다.

## Python (백준 표준 입력 대응)

```python
def solution(n, a, b):
    round_count = 0
    while a != b:
        a = (a + 1) // 2
        b = (b + 1) // 2
        round_count += 1
    return round_count
```

## JavaScript (Node.js, 백준 표준 입력 대응)

```javascript
function solution(n, a, b) {
  let roundCount = 0;
  while (a !== b) {
    a = Math.floor((a + 1) / 2);
    b = Math.floor((b + 1) / 2);
    roundCount++;
  }
  return roundCount;
}
```

### 시간 복잡도

- O(log N)
    - 매 라운드마다 번호가 절반 가까이 줄어들기 때문에, 최대 라운드 수는 log₂(N)이다.
    - N = 2^20이어도 약 20 라운드만 계산하면 된다.

### 느낀점 or 기억할 정보
- 토너먼트 번호 갱신은 항상 (번호 + 1) // 2 로 처리할 수 있어, 홀수/짝수 분기(if a%2…) 검사가 필요 없다.
- 토너먼트 문제의 공통 규칙:
    다음 라운드 번호 = (현재 번호 + 1) // 2
