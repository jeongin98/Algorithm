### 문제 분석 요약
- 다단계 조직 구조(트리)에서 판매 수익을 위로 전달하는 문제.
- 판매 금액의 10%를 추천인(부모)에게 전달. 본인은 90%만 가짐
- 부모는 또 상위 부모에게 전달하며 반복하는 구조.

### 알고리즘 설계

#### 필요한 값

- 입력:
    - enroll: 판매원 이름 리스트
    - referral: 추천인 이름 리스트
    - seller: 판매자 이름 리스트
    - amount: 각 seller의 판매 개수
- 출력: 각 가입자가 얻은 총 수익 리스트

#### 풀이 순서
1. 이름 → 인덱스 매핑 딕셔너리 idx 만들기
2. 추천인 정보로 parent 배열 만들기
3. 모든 사람의 이익을 담을 profit 배열 만들기
4. zip(seller, amount) 돌면서
    - 판매 금액 계산
    - 본인에게 90%, 부모에게 10% 전달
    - 부모로 계속 올라가는 반복 수행
5. 최종 profit 출력

## Python (백준 표준 입력 대응)

```python
def solution(enroll, referral, seller, amount):
    n = len(enroll)
    # 이름 → 인덱스 매핑
    idx = {name: i for i, name in enumerate(enroll)}
    # 부모 인덱스 테이블
    parent = [-1] * n
    for i, ref in enumerate(referral):
        if ref != "-":
            parent[i] = idx[ref]
    # 수익 저장 배열
    profit = [0] * n

    # 판매 내역 처리
    for s, a in zip(seller, amount):
        cur = idx[s]
        money = a * 100
        while cur != -1 and money > 0:
            commission = money // 10
            profit[cur] += (money - commission)
            money = commission
            cur = parent[cur]
    return profit

```

## JavaScript (Node.js, 백준 표준 입력 대응)

```javascript
function solution(enroll, referral, seller, amount) {
  const n = enroll.length;
  const idx = {};
  enroll.forEach((name, i) => {
    idx[name] = i;
  });

  const parent = new Array(n).fill(-1);
  referral.forEach((ref, i) => {
    if (ref !== "-") {
      parent[i] = idx[ref];
    }
  });

  const profit = new Array(n).fill(0);

  seller.forEach((s, i) => {
    let cur = idx[s];
    let money = amount[i] * 100;
    while (cur !== -1 && money > 0) {
      const commission = Math.floor(money / 10);
      profit[cur] += (money - commission);
      money = commission;
      cur = parent[cur];
    }
  });

  return profit;
}

```

### 시간 복잡도

- O(M × H)
    -  판매 건수 M
    - 한 판매가 트리 높이 H 만큼 위로 올라감

### 느낀점 or 기억할 정보
- 부모를 찾아가는 구조 => 부모만 저장해둔 리스트 + while과 cur로 반복해서 찾아올라가기
- 다단계 구조 = 트리 문제라고 보면 매우 쉬워진다.
