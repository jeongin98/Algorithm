### 문제 분석 요약
- 노드들의 (x, y) 좌표와 노드 번호가 주어진다.

- y가 높을수록 상위(루트에 가까움),
x가 작을수록 왼쪽 자식, x가 클수록 오른쪽 자식이 된다.

- 이 규칙에 따라 이진트리를 직접 구성한 뒤
전위 순회(preorder), 후위 순회(postorder) 결과를 반환하는 문제다.

핵심 포인트:
1. y 내림차순 정렬 → 트리의 높이 순(루트부터)
2. 같은 y에서는 x 오름차순 → 같은 층에서는 왼쪽이 먼저
3. 정렬된 순서로 이진트리 구성
4. 전위, 후위 순회 수행

### 알고리즘 설계

#### 필요한 값

- 입력: nodeinfo (각 노드의 좌표가 들어있는 2차원 배열)
- 출력: [preorder_list, postorder_list]
    - 전위 순회 결과(노드 번호)
    - 후위 순회 결과(노드 번호)

#### 풀이 순서
1. 노드 데이터 구조화
 (x, y, node_number) 형태로 변환한다.

2. 정렬
    - y 기준 내림차순 → 높은 위치의 노드(루트 후보)를 먼저 배치
    - x 기준 오름차순 → 같은 층에서 왼쪽 노드를 먼저 배치

3. 트리 구성
    - 첫 번째 노드를 루트로 설정한 뒤
    남은 노드를 하나씩 삽입한다.

    - 삽입 규칙:
    if x < cur.x → 왼쪽 자식으로 이동
    if x > cur.x → 오른쪽 자식으로 이동
    
4. 전위(preorder) 순회
5. 후위(postorder) 순회
6. 순회 결과 반환



## Python (백준 표준 입력 대응)

```python
def solution(nodeinfo):
    import sys
    sys.setrecursionlimit(10**7)
    
    # 노드 정보를 (x, y, num) 형태로 만듦
    nodes = [
        (x, y, i+1)
        for i, (x, y) in enumerate(nodeinfo)
    ]
    # 정렬: y 내림차순, x 오름차순
    nodes.sort(key=lambda t: (-t[1], t[0]))
    
    # 노드 정의
    class Node:
        __slots__ = ("x","y","num","left","right")
        def __init__(self, x, y, num):
            self.x = x
            self.y = y
            self.num = num
            self.left = None
            self.right = None
    
    # 트리 구성
    root = Node(*nodes[0])
    for x, y, num in nodes[1:]:
        cur = root
        node = Node(x, y, num)
        while True:
            if x < cur.x:
                if cur.left is None:
                    cur.left = node
                    break
                else:
                    cur = cur.left
            else:  # x > cur.x
                if cur.right is None:
                    cur.right = node
                    break
                else:
                    cur = cur.right
    
    # 순회 함수들
    preorder_list = []
    def preorder(n):
        if not n:
            return
        preorder_list.append(n.num)
        preorder(n.left)
        preorder(n.right)
    
    postorder_list = []
    def postorder(n):
        if not n:
            return
        postorder(n.left)
        postorder(n.right)
        postorder_list.append(n.num)
    
    # 순회 실행
    preorder(root)
    postorder(root)
    
    return [preorder_list, postorder_list]
```

## JavaScript (Node.js, 백준 표준 입력 대응)

```javascript
function solution(nodeinfo) {
  // 노드 정보를 { x, y, num } 형태로 만듦
  const nodes = nodeinfo.map((xy, i) => ({
    x: xy[0],
    y: xy[1],
    num: i + 1
  }));
  // 정렬: y 내림차순, x 오름차순
  nodes.sort((a, b) => {
    if (b.y !== a.y) return b.y - a.y;
    return a.x - b.x;
  });
  
  // 노드 클래스
  class Node {
    constructor(x, y, num) {
      this.x = x;
      this.y = y;
      this.num = num;
      this.left = null;
      this.right = null;
    }
  }
  
  // 트리 구성
  const root = new Node(nodes[0].x, nodes[0].y, nodes[0].num);
  for (let i = 1; i < nodes.length; i++) {
    const { x, y, num } = nodes[i];
    let cur = root;
    const node = new Node(x, y, num);
    while (true) {
      if (x < cur.x) {
        if (cur.left === null) {
          cur.left = node;
          break;
        } else {
          cur = cur.left;
        }
      } else {  // x > cur.x
        if (cur.right === null) {
          cur.right = node;
          break;
        } else {
          cur = cur.right;
        }
      }
    }
  }
  
  // 순회 함수들
  const preorderList = [];
  function preorder(n) {
    if (!n) return;
    preorderList.push(n.num);
    preorder(n.left);
    preorder(n.right);
  }
  
  const postorderList = [];
  function postorder(n) {
    if (!n) return;
    postorder(n.left);
    postorder(n.right);
    postorderList.push(n.num);
  }
  
  // 순회 실행
  preorder(root);
  postorder(root);
  
  return [preorderList, postorderList];
}

```

### 시간 복잡도

- O(N log N)
    - 정렬: O(N log N)
    - 트리 구성: 평균 O(N log N)
    - 순회: O(N)

### 느낀점 or 기억할 정보
- 이 문제는 “트리를 내가 직접 구성해야 하는 문제”다. 이 문제에서는 Node 클래스를 쓰는 것이 사실상 가장 효율적이다. 
    - 좌표만 주어지기 때문에, 다음 사항을 모두 개발자가 구현해야 한다.
        - 루트 찾기
        - left/right 배치
        - 트리 구조 구축
        → 그래서 Node 클래스를 만들어 left/right 속성을 직접 관리하는 방식이 가장 직관적이고 깔끔하다.
    - (하지만 Node 클래스를 사용하는 것이 이진트리 문제의 ‘정석’은 아니다.)
- 재귀 깊이 제한도 주의해야 한다
    -  트리가 한쪽으로만 치우치는 경우 최악의 재귀 깊이가 N이 될 수 있다.
        그래서 Python에서는 보통: **sys.setrecursionlimit(10**6 ~ 10**7)** 정도로 여유 있게 설정한다.
