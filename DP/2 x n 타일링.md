### 문제 분석 요약
- 2×n 크기의 직사각형 바닥을 1×2 또는 2×1 크기의 타일로 채우는 방법의 수를 구하는 문제이며,
- 단, 결과가 매우 커질 수 있으므로 1,000,000,007로 나눈 나머지를 반환해야 한다.

### 알고리즘 설계

#### 필요한 값

- 입력: n(가로 길이)
- 출력: 2 × n 크기의 바닥을 1×2, 2×1 타일로 채우는 경우의 수를 1,000,000,007로 나눈 나머지

#### 풀이 순서
1. 점화식 도출
    - 맨 마지막을 어떻게 할 것인지만 생각하면 된다. 다음 두 가지가 있다.
    - 세로로 한 개 놓는 경우 → d[n-1]
    - 가로로 두 개 + 세로로 두 개 놓는 경우 → d[n-2]
        → 따라서 d[n] = d[n-1] + d[n-2]
2. 초기값 설정
    - d[1] = 1
    - d[2] = 2

3. 반복문으로 DP 계산
    3부터 n까지 d[i] = (d[i-1] + d[i-2]) % MOD 수행
    매번 % MOD를 해주는 이유는 숫자가 너무 커지지 않게 하기 위해서

4. 최종 결과 반환
    return d[n]

## Python (백준 표준 입력 대응)

```python
def solution(n):
    MOD = 1000000007
    # 초기화
    d = [0] * (n + 1)
    d[1] = 1
    d[2] = 2

    # 점화식
    for i in range(3, n + 1):
        d[i] = (d[i-1] + d[i-2]) % MOD # 나머지

    return d[n]
```

## JavaScript (Node.js, 백준 표준 입력 대응)

```javascript
function solution(n) {
    const MOD = 1000000007
    const d = new Array(n+1).fill(0);

    d[1] = 1;
    d[2] = 2;

    for (let i = 3; i <= n; i++) {
        d[i] = (d[i - 1] + d[i - 2]) % MOD;
    }

    return d[n];
}
```

### 시간 복잡도

- O(n)
    - 반복문이 for i in range(3, n + 1) 형태로 딱 n-2번만 돌고
    - d[i-1], d[i-2]는 이미 계산되어 배열에 저장된 값을 즉시 참조(O(1)) 

### 느낀점 or 기억할 정보
- 타일을 배치하는 경우의 수는 피보나치 수열과 동일한 패턴을 가진다.
- DP는 “초기화 + 점화식” 두 가지가 핵심 구조이다.
