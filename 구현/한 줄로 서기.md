### 문제 분석 요약
- 사람은 총 N명(1 ≤ N ≤ 10)

- 각 사람의 키는 1부터 N까지, 모두 다름.

- 각 사람은 “자신보다 키가 큰 사람이 왼쪽에 몇 명 있었는가”를 기억함.

- 입력은 키가 1인 사람부터 N인 사람까지의 “왼쪽 큰 사람 수” 리스트로 주어짐.

- 조건을 만족하도록 실제 줄의 순서를 찾아야 함.

- 출력은 왼쪽에서부터 사람들의 키 순서를 공백으로 구분해 출력.

### 알고리즘 설계

#### 필요한 값

- 입력:
    - N: 사람 수
    - L[i]: 키가 i인 사람이 기억하는 "왼쪽에 자신보다 큰 사람 수"
- 출력: 조건을 만족하는 최종 줄 서기 순서 (예: 4 2 1 3)

#### 풀이 순서
1. 초기화:

빈 리스트 answer = [] 생성.

2. 큰 키부터 줄 세우기:
    - 키가 큰 사람부터(즉, N → 1) 한 명씩 answer에 끼워 넣음.
    - 이유: 이미 줄에 서 있는 사람들은 모두 자신보다 크므로, “왼쪽에 자신보다 큰 사람 수” = “삽입 위치 인덱스”가 됨.

3. 삽입 로직:
i번째 사람(키 = i)을 L[i] 인덱스에 삽입
→ 파이썬: answer.insert(L[i], i)
→ JS: answer.splice(L[i], 0, i)

4. 모든 사람을 배치 후 출력:
    리스트 answer를 출력하면 최종 줄 순서가 됨.

## Python (백준 표준 입력 대응)

```python
import sys

input = sys.stdin.readline
N = int(input().strip())
L = [0] + list(map(int, input().split()))  # 1-index 맞추기

answer = []
for i in range(N, 0, -1):   # 키가 큰 사람부터
    answer.insert(L[i], i)

print(*answer)
```

## JavaScript (Node.js, 백준 표준 입력 대응)

```javascript
const fs = require("fs");

const data = fs.readFileSync(0, "utf8").trim().split(/\s+/).map(Number);
const N = data[0];
const L = [0, ...data.slice(1)]; // 1-index

const answer = [];
for (let i = N; i >= 1; i--) {    // 키가 큰 사람부터
  answer.splice(L[i], 0, i);      // 해당 인덱스에 i를 끼워넣기
}

console.log(answer.join(" "));
```

### 시간 복잡도

- O(N)
    - 각 사람마다 리스트 중간에 삽입 수행

### 느낀점 or 기억할 정보
- “왼쪽에 나보다 큰 사람 수” → 삽입 인덱스 위치라는 관점이 핵심이다

- 작은 수(키가 작은 사람)부터 세우면 복잡해지지만,
큰 키부터 세우면 항상 정확한 자리 계산이 가능하다

- insert()나 splice()로 중간 삽입을 직접 시뮬레이션하는 전형적인 구현/시뮬레이션 문제이다

- 입력 순서가 “키 순서대로” 주어진다는 점을 헷갈리지 말기!
