### 문제 분석 요약
이 문제는 **지그재그(뱀 형태)**로 상자가 층마다 쌓여 있을 때,
특정 번호 num 상자를 꺼내기 위해 그 상자 위에 있는 층들에 놓인 상자를 모두 꺼내야 하므로
“num이 포함된 층부터 위의 층까지 몇 개가 존재하는가?”를 계산하는 문제이다.

핵심 다음 두 가지예요.
1. num이 어느 층에, 어느 열(column)에 있는지 결정하기
2. 마지막 층(최상단)이 꽉 차지 않은 경우, col 위치에 실제 상자가 존재하는지 체크하기

### 알고리즘 설계

#### 필요한 값

- 입력:
    - n : 전체 상자 수
    - w : 한 층에 쌓는 상자 수
    - num : 찾고자 하는 상자 번호

- 출력: num 상자를 꺼내기 위해 꺼내야 하는 총 상자 개수

#### 풀이 순서
1. 총 층 수 계산
    - R = ceil(n / w)

2. num이 위치한 층 계산
    - 0층부터 시작한다고 가정하면
    r = (num - 1) // w

3. 그 층에서 num의 column 위치 계산
    - 해당 층이 왼→오 방향이면
        col = (num - 1) % w
    - 해당 층이 오→왼 방향이면
        col = w - 1 - ((num - 1) % w) 

4. 일단 num 포함 층부터 최상단 층까지는 모두 꺼내야 함

    - answer = R - r

5. 최상단 층이 완전히 채워져 있지 않은 경우 보정

    - 마지막 층의 상자 개수: k = n % w

    - 마지막 층 인덱스: top = R - 1

    - 마지막 층의 방향에 따라 실제 상자가 채워진 column 범위를 계산

    - 만약 col 위치가 비어있는 영역이면
        → 그 층의 상자를 꺼낼 필요가 없어 answer -= 1

6. 최종 answer 반환

## Python (백준 표준 입력 대응)

```python
def solution(n, w, num):
    # 총 층 수
    R = (n + w - 1) // w  # ceil(n/w)
    # num이 있는 층(0부터)
    r = (num - 1) // w
    # 해당 층에서의 열 위치
    pos = (num - 1) % w
    col = pos if (r % 2 == 0) else (w - 1 - pos)
    # 기본 꺼내야 할 층 수
    answer = R - r
    # 마지막 층이 꽉 찼는가?
    k = n % w
    if k != 0:
        top = R - 1
        if top % 2 == 0:
            # 왼→오 방향이면 열 0..k-1 채워짐
            if col >= k:
                answer -= 1
        else:
            # 오→왼 방향이면 열 (w-k)..(w-1) 채워짐
            if col < (w - k):
                answer -= 1
    return answer

```

## JavaScript (Node.js, 백준 표준 입력 대응)

```javascript
function solution(n, w, num) {
    const R = Math.ceil(n / w);
    const r = Math.floor((num - 1) / w);
    const pos = (num - 1) % w;
    const col = (r % 2 === 0) ? pos : (w - 1 - pos);
    let answer = R - r;

    const k = n % w;
    if (k !== 0) {
        const top = R - 1;
        if (top % 2 === 0) {
            if (col >= k) {
                answer -= 1;
            }
        } else {
            if (col < (w - k)) {
                answer -= 1;
            }
        }
    }

    return answer;
}

```

### 시간 복잡도

- O(1)
    → 반복문이나 배열 생성 없이 즉시 계산하는 문제

### 느낀점 or 기억할 정보
- 지그재그(뱀행) 배열에서 위치 찾기는 자주 등장함
    - 짝수 층: left → right
    - 홀수 층: right → left

- “마지막 행(층)이 꽉 차 있지 않은 경우의 boundary 조건”을 자주 틀리므로 주의

- 시뮬레이션이 아닌 수학적 계산(규칙 발견) 기반의 문제

- 구현은 단순하지만, 좌표 변환/방향 기반 인덱싱이 핵심

- 프로그래머스 신규 문제들 중에서 흔하게 나오는 “규칙성 + 구현” 유형이다.
